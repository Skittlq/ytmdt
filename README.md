# YouTube Media Downloader Tool

i dont like relying on websites to download stuff off of youtube so i made this yt-dlp wrapper with a gui and its pretty neat

its only for windows because im lazy

## features:

- auto updates yt-dlp and ffmpeg
- choose between 144p to 4k
- choose file format (mp4, mkv, webm, mp3, wav, m4a, opus)
- choose between vp9 and avc1 codec
- download videos or entire playlists
- storage estimation

## credits

all the work is done by yt-dlp and ffmpeg, theyre both amazing tools!
